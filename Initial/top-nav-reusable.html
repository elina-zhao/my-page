Start your own podcast in minutes.

这是演示用 Hero 区域。实际使用把 <div id="topnav"> 放到你页面 Hero 之上即可。

一步调用（就两步）

1. 把 top-nav.js 拷进你的项目，页面里引入（组件会自动注入自己的样式，不用再复制 CSS）。
2. 一行 TopNav.mount({...})，菜单/文案/Logo/主题全在这个对象里配置。
<!-- 引入组件（自带样式） -->
<script src="top-nav.js"></script>
<!-- 挂载点（可选，不写会自动插到页面顶部） -->
<div id="topnav"></div>

<script>
TopNav.mount({
  theme: 'dark',              // 'dark' | 'light'
  mountTo: '#topnav',         // 挂到上面这个容器；可省
  logo: { type:'text', badge:'P', text:'Podbean', href:'#' },
                              // 图片版：{ type:'image', src:'logo.png', href:'#' }
  navLinks: [
    { label:'Pricing', href:'#' },
    { label:'Podcasting', dropdown:true, columns:[
        { title:'Podcast Features', links:[
            { label:'Podcast Hosting', desc:'一句话说明', href:'#' },
            { label:'Podbean AI',      href:'#' }   // 不带 desc = 分类样式
        ]}
    ]}
  ],
  search:  { show:true, placeholder:'Search' },
  actions:{ login:{ label:'Log in', href:'#' },
            cta:{   label:'Sign up free', href:'#', style:'primary' } }
});
</script>

换品牌 / 换主题

换配色不用动代码：在页面 CSS 里覆盖 .twnav{ --twn-c-accent: #你的品牌色; } 等 --twn-* 变量即可（完整变量清单见 top-nav.js 文件顶部注释）。
浅色页面：把 theme 改成 'light'，或对根元素加 .twnav--light。
不想要搜索框：search:{ show:false }；按钮要描边样式：cta:{ style:'ghost' }。
